# Practical editing methods

These are editing methods, not verified desktop click paths. Select operations and parameters from live schemas. For guidance-only tasks, explain methods without implying execution.

## Build a cut

Inspect project/media and requested orientation/duration. Choose source in/out ranges and timeline positions. Import missing assets once, assemble base shots, inspect resulting IDs/ranges, then add layers/text/music/effects. Verify gaps, black frames, ripple behavior and A/V sync. Preserve speech meaning when shortening pauses.

## Captions

Finish structural edits where practical. Inspect existing caption elements, then generate only what is needed. Correct names, numbers, acronyms and negations before styling. Distinguish transcription from translation. Retrieve current style/font IDs; inspect line breaks, word highlights and timing. Preview beginning/middle/ending at viewing size, including muted playback.

## Motion

Inspect original transforms and keys. Choose times in the schema's units; set supported properties while preserving unrelated keys. Review interpolated movement and endpoints. For gentle emphasis, a modest scale increase is a creative starting point, not an Edits default. Check subject framing throughout.

## Color

Inspect source log/HDR, project dynamic range and existing transforms. Use one correct technical conversion where needed; balance exposure/white balance before a creative look. Check skin tones, clipped highlights, crushed shadows and shot consistency on rendered frames. Creative LUT and technical log conversion are different operations.

## Audio

Inspect speech, background, music and SFX separately. Compare enhancement against original; avoid speech damage. Balance music under voice and smooth transitions using supported fades/ducking. Read gain units. Choose loudness targets for the deliverable; no fixed Edits desktop target is established by launch sources.

## Repurpose aspect ratio

Inspect source dimensions and subject movement. Reframe individually after changing canvas; preserve text/action and use split screen only if useful. Preview whole shots and captions. Suggested 9:16/16:9 deliverables are recommendations, not an exhaustive Edits menu.

## Export

Check destination, resolution, frame rate, orientation, dynamic range and actual export options. Prefer a final encode from source media. Inspect async job completion, then file existence, nonzero size, duration, dimensions and audio as tools permit. Report unsupported settings instead of silent substitutions. Upscaling cannot restore missing source detail.

## Publish when requested

Finish edit/preview first. Inspect account and publishing surface; use requested caption, tags, location and trial-reel preference. Resolve real music eligibility and posting blockers. Existing authorization and host permissions govern posting; report returned post identity/visible success, not just a button click.

## Narrow failure checks

| Problem | Diagnosis |
| --- | --- |
| Missing editing action | Home/editor discovery and selected project |
| Wrong clip modified | Stale ID, source/timeline mismatch, ripple edits |
| Duplicate captions | Existing elements before regeneration |
| Audio shifted | Extract/replace/slip/speed changes |
| Washed-out grade | Log conversion and HDR/output handling |
| Text offscreen | Layout across animation, not first frame only |
| Export hanging | Job/error, destination availability, source status; no duplicate queues |
| Mobile tutorial mismatch | Check desktop control/capability first |
| Unknown enum/action | Read current schema/catalog; do not guess |
