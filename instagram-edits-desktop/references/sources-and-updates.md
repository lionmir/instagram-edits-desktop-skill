# Sources and updates

Baseline: **2026-11-05**, America/New_York. Versioned snapshot plus live discovery; no promise to know future releases.

## Evidence order

1. Live tools/resources and successful readbacks establish executable capability now.
2. Official desktop pages establish product features, not tool argument schemas.
3. Installed metadata and bundled strings give build-specific hints, not execution proof.
4. Mobile/general documentation explains concepts without establishing desktop parity.

## Primary sources

- [Desktop product page](https://edits.instagram.com/desktop/): requirements, editing, delivery.
- [Desktop launch announcement](https://edits.instagram.com/blog/edits-desktop-video-editor/): dated feature evidence, MCP, roadmap.
- [Edits blog](https://edits.instagram.com/blog/): subsequent releases; open relevant articles rather than inferring availability from titles.
- [Edits tutorials](https://edits.instagram.com/#tutorials): direct topic links in [features.md](features.md).
- [Claude Code skills](https://code.claude.com/docs/en/skills): skill format, installation and invocation.
- [OpenAI skills](https://learn.chatgpt.com/docs/build-skills): skill format and `.agents/skills` discovery.

Edits pages were retrieved through ordinary HTTPS curl when web extraction failed. No full manuals, transcripts, videos, screenshots or Meta binaries are redistributed; this package contains original instructions, short summaries and links.

## Local evidence and limits

Research Mac had `/Applications/Edits.app`. Read-only Info.plist inspection identified 454.0.0 / 454.0.0.38.112, build 1106192771, minimum macOS 15.1. Read-only executable-string inspection supplied Automation labels, server identifier, candidate resource URIs and action names. Bundled strings may include inactive code.

Native UI inspection returned `Accessibility error: AXError.cannotComplete`. No Automation setting was changed, no token was retrieved, no authenticated MCP session connected, and no project edited/exported during package creation. No end-to-end client editing test was completed.

## Refresh procedure

1. Read installed version through metadata or exposed version tool; record date/source.
2. Check official desktop page and relevant newer blog posts; separate shipped, platform-specific and roadmap claims.
3. Discover current tool manifests, capabilities, resources and catalogs. Inspect home/editor surfaces when the task permits. Do not create an unwanted project merely to enumerate tools.
4. Update evidenced purpose, screen, schema, units, dependencies, async behavior and implementation status. Distinguish unsupported from uninspected.
5. For execution validation, use a user-authorized sample/duplicate project. Discovery does not test editing. Redact tokens, project names, paths and private media from shared evidence.
6. Revise baseline, validate skill and rebuild archive without caches, private media, app binaries or client credentials/configurations.

For “all functions,” return live inventory and coverage boundary. If disconnected, identify bundled action map as provisional and give next connection step.
